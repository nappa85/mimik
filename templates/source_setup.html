Register local materials

The instance owner supplies lawfully obtained manuals. This page gives local setup instructions; it is not a browser upload endpoint.

  1. Keep the original PDF and extraction artifacts in private local storage.
  2. Use the containerized extraction/preparation workflow documented in docs/sources-and-retrieval.md. It preserves tables, metadata and original page images.
  3. Register the prepared bundle with the local executable:
mimik import-source --bundle PATH_TO_PREPARED_BUNDLE --pdf PATH_TO_ORIGINAL_PDF

Registration adds an unreviewed source. Reviewed rules lookup requires explicit source inspection and completeness; a sheet needs a runtime definition the Owner registers and approves.
