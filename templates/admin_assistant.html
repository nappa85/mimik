{% endif %} {% if let Some(device) = view.device %}

GPU: {{ device.description }} ({{ device.name }} in its sandbox, PCI {{ device.pci }}, render node {{ device.node }}, {{ device.total_mib }} MiB).

Sandboxed, with graphics-driver access: the model server runs in the level-1 sandbox: no network, no other processes and no access to the user's files. Besides the runtime and the model it reads read-only system libraries, system driver data (Vulkan ICD manifests, libdrm and drirc data), the card's sysfs attributes and the CPU topology, and it can issue any ioctl on its one render node, so its exposure to the kernel's graphics driver is wider than on the CPU path. Start Mimik with --assistant-device cpu to run it on the CPU instead.
