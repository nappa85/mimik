Ruleset registry

Registering a stable game/edition identity lets prepared sources and records name it exactly. It does not approve evidence, publish a sheet definition, enable rules or authorize campaigns. IDs and labels are immutable once registered; there is no rename or delete. The same registrations are available to the local operator CLI.

Register a game edition

Add an exact legacy alias
